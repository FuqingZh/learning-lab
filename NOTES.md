# Teaching Notes

These are this learner's current preferences, not a universal pedagogy.
The latest explicit learner request takes precedence over older preferences.

- Teach in Chinese; retain established English technical terms and explain them
  when first needed. Do not turn English labels into an unexplained map.
- Treat the learner as a capable reasoner and a domain beginner where evidence
  is absent. Systems judgment does not imply familiarity with frontend syntax.
- Build the whole-system frame before detail. Explain the problem, historical
  conditions and proposals, mechanisms, modern tradeoffs, and then a relevant
  repository case. History must be sourced, not an invented origin story.
- Teach a coherent problem or understanding process. No default tiny lessons,
  fixed duration, concept count, question quota, or theory/detail percentage.
  Necessary detail must be explained; optional detail can be deferred.
- Give sufficient connected explanation and a worked example before expecting
  independent use. Do not make the learner reconstruct missing instruction by
  answering a series of questions.
- Use plain syntax in a new example. Expand shorthand or bridge it before use;
  do not teach a new mechanism through several unexplained language features.
- Welcome direct questions. Follow a useful branch with a clear purpose and
  return point; reconnect its conclusion to the main explanation. The learner
  may intentionally change the main route.
- A knowledge node is not a lesson or a compulsory quiz. Check understanding
  at meaningful unit/stage boundaries; clarification replies need not end in
  questions. Stopping or skipping a check creates no failure or mastery claim.
- Repository details serve transferable understanding, not memorization of
  local routes, classes, versions, or table names.
- Keep records and review mechanics unobtrusive. Preserve navigation separately
  from capability evidence. Do not make the learner re-explain these preferences.
- Adapt the current explanation automatically; propose lasting changes to
  mission, stage route, global preferences, or skill rules for confirmation.
- Keep full original conversations private and explicitly scoped. Use verified
  sources or private exports when available; never reconstruct a transcript
  from summaries. Database and automatic navigation engine are deferred.
