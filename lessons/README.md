# Lessons

Lessons are reusable teaching artifacts grouped by transferable capability
track. Their filenames describe the taught concept rather than a global lesson
number.

- [Bioinformatics Systems](bioinformatics-systems/)
- [Scientific AI Platforms](scientific-ai-platforms/)

Create a track directory only after it has at least one reusable lesson.

## Prepared coherent-teaching pilot

[From document updates to React](scientific-ai-platforms/react-from-document-updates.md)
provides a complete beginner bridge and a dependency-free HTML example.
Prepared material is not evidence that the learner has completed it.
