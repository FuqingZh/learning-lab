第 2 课：蛋白质注释究竟是什么

SeqEvi 学习轨道 · 生物学与计算推理基础

本课目标：面对一条工具输出，能区分输入事实、计算证据、生物学推断和最终注释陈述，不把“相似”直接说成“功能已经证明”。

1. 序列是一种物质配方，不是功能标签

蛋白质是由氨基酸残基通过肽键连接形成的链。FASTA 中的字母是残基类型的符号表示。不同侧链具有不同大小、电荷、疏水性和反应性；残基顺序影响链如何折叠，折叠形成的三维形状又影响结合、催化、支撑、运输和信号等能力。

氨基酸序列
    ↓ 物理化学相互作用与细胞环境
三维结构、动态构象与结构域组合
    ↓ 结合位点、活性位点、相互作用界面
分子能力
    ↓ 细胞位置、伙伴、表达与调控
生物学作用

这条链解释了为什么序列包含功能线索，也解释了为什么仅凭序列通常不能把全部生物学功能当作直接观测值。

2. 注释是带证据来源的陈述集合

“蛋白注释”不是一个单独字段。它可以包含蛋白名称、家族、结构域、活性位点、催化反应、分子功能、通路、亚细胞定位、跨膜区、信号肽及其他特征。关键不只是标签内容，还包括标签来自实验、人工审阅、序列比较、统计模型还是自动规则。

层次例子性质
输入事实规范化序列是 MKWV…，长度 312由输入直接得到
计算证据与数据库序列形成显著局部比对；某 Pfam profile 在 42–186 命中算法与资源共同产生
生物学推断可能属于某同源家族；该区间可能折叠为某结构域从证据到生物含义的推理
注释陈述含某结构域；可能具有某催化活性；关联某 GO term可供数据库和用户消费的结构化主张
溯源与边界数据库版本、模型 ID、分数、阈值、规则、证据类型说明主张为什么可信、适用于什么条件

3. 为什么比较序列能够提供线索

共同祖先产生的蛋白会在演化中积累替换、插入和删除。如果某些残基对折叠、结合或催化特别重要，破坏它们的变异往往更难保留下来，于是相关位置会表现得更保守。比较未知序列与已研究序列，可以寻找这种超过随机预期的保守模式。

相似性与同源性不同：相似性是可计算的程度；同源性是“是否源自共同祖先”的关系。通常不说“70% 同源”，而说“70% 序列一致性，支持同源关系”。同源也不自动等于功能完全相同。

4. 比对实际在计算什么

比对把 query 与 subject 的字符安排到对应位置，并允许插入 gap。每个残基配对由替换矩阵打分：在演化中常见或化学性质相近的替换通常惩罚较小，不合理替换惩罚较大；开启和延伸 gap 也有代价。算法寻找高分局部或全局对应关系。

Query:   M A K V L - G D L G T
           | : |   | | | |
Subject: M S K V L A G D L G T

总分 = 残基配对分数之和 - gap 代价

原始高分还不够，因为数据库越大，偶然出现高分片段的机会越多。E-value 表示在给定搜索空间中，按随机模型预期出现“同样好或更好”匹配的次数。越小通常越显著，但显著只表示“不太像随机巧合”，并不自动证明具体功能。

5. 从显著相似到功能标签仍有距离

  • 比对可能只覆盖一个短结构域，而不是整个蛋白。
  • 同一家族的 paralog 可能演化出不同底物或调控方式。
  • 多结构域蛋白的整体作用取决于结构域组合和顺序。
  • 关键催化残基可能已经突变，整体相似仍然很高。
  • 数据库中的来源注释本身可能只是计算转移，而非实验事实。
  • 细胞定位、物种背景、相互作用伙伴和表达条件也影响实际作用。
安全推理原则：工具直接支持多强的主张，就输出多强的主张。结构域命中首先支持“存在该结构域的证据”，不应无条件升级为“整条蛋白已经证明执行某个精确反应”。

6. 不同工具位于推理链的不同位置

工具或资源主要比较对象直接产物的典型意义
DIAMONDquery 序列对大型蛋白序列库快速局部相似性命中与统计量
eggNOG-mapper搜索结果加正交群和功能知识正交关系及由其转移的广泛功能注释
HMMER + Pfam序列对家族或结构域的 profile HMM某区间匹配某蛋白家族或结构域模型
InterProScan序列对多个成员数据库的 signatures整合的家族、结构域、位点等匹配；具体内容取决于启用的应用
dbCAN序列对 CAZyme 专门模型和参考知识碳水化合物活性酶家族相关证据
SeqEvi不发明新的生物学搜索模型调用明确适配器、验证身份、缓存证据并交付可消费结果

后续课程会逐个拆解这些方法。当前只需掌握：它们的直接输出、推断层次和适用主张并不相同。

7. 为什么 SeqEvi 叫 Sequence Evidence

同一条序列可以同时拥有 eggNOG 的正交证据、Pfam 的结构域证据和 dbCAN 的 CAZyme 家族证据。这些证据互补，但行粒度、字段和语义不同。SeqEvi 保留适配器原生语义，而不把所有结果硬压进一张“万能功能表”。EvidenceKey 还把工具、数据库、参数和解释合同固定下来，使注释主张可以审计。
