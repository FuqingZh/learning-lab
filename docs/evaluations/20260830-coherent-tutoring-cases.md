# 连贯教学内容审查场景

这些是本次获准改造的补充审查场景，不是新模型跑分。使用合成情境，不含
原始私人问答。现有六场景 scorecard、hash 与 state replay 契约保持不变。
实现代理的内容自审不能替代独立评审、模型行为运行或真实学习体验。

| 情境 | 可观察的合格表现 | 反例 / 失败信号 |
| --- | --- | --- |
| 擅长系统推理，但首次接触 React | 以显示更新问题开始；明确语法证据缺口，提供桥梁 | 由 program 标签推断已经会解构和 JSX |
| 用户问 React 是不是语法 | 先区分语言与 library，使用已经解释的调用作例子 | 用 props、reconciliation、hooks 互相定义 |
| 用户要求别再拆成碎片 | 连贯解释完整问题，澄清可不以小测结束 | 换名称后继续逐句填空 |
| 主线 → library → 函数调用两层追问 | 保留父子关系、为什么展开与具体返回点，返回时解释联系 | 只记最后术语，或关闭子分支时丢掉父分支 |
| 旧 resume 指向 typed props，但先备知识不足 | 当前问题优先，准备前置桥梁，不篡改旧证据 | 机械恢复旧任务或把全部旧学习清零 |
| 用户经提示完成示例 | 保留 assisted；需要时另给不同案例观察独立使用 | 把重复刚才答案登记成 fresh transfer |
| 来源只回读部分对话或历史来源不足 | 明确 partial/missing，限定结论，不补写原文或动机 | 结构检查通过便宣称完整采集或历史优先权 |
| 用户主动改换方向 | 暂存未决分支，新请求可以改变主线 | 强制回原课，或把暂存写成 resolved |

审查方式：阅读当前 skill 与四份 references、NOTES、近期 curriculum 和
样课，逐项记录证据与缺口。不要以必须包含某个英文句子作为教学质量标准。
对涉及导航的结构声明，使用真实 validator 正负例测试；对语言解释和课堂
适配，只能给内容审查结论，不能用文件存在断言代替行为验证。

## 真实试学时观察什么

先询问是否愿意开始准备好的桥接课，而非自动恢复旧习题。围绕一个完整
例子展开，允许随时提问或停止。在自然节点收集两类不同证据：

- 体验：背景是否充分、是否知道当前问题、分支返回是否自然；不逐轮打分。
- 学习：能否在不同展示例子中解释语言、计算、描述与文档更新的关系；
  记录是否给过提示，不由“讲得很好”推断独立能力。

若再次发生未铺垫术语链，记录具体位置和可能原因，先调整课内示例；
涉及持久路线或 skill 的改动，再向用户说明候选及依据。一次试学只能支持
这一堂课的有限结论，不能证明长期保持或其他领域可靠。
