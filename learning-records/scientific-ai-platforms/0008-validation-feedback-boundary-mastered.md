# Contract validation and scientific acceptance are distinguished

The learner can now separate deterministic contract validation, user feedback,
and scientific correctness. A `result_ready` outcome proves only that the
configured platform checks passed; a positive user reaction is a satisfaction
or evaluation signal; neither alone proves that the analysis is scientifically
correct.

The learner correctly assigns unresolved scientific judgment to expert review.
Future lessons can extend this by distinguishing cases that require an explicit
human rubric from cases with a genuinely independent, typed deterministic
scientific oracle.

## Evidence

In a fresh label-swapping scenario on 2026-08-17, the learner explained that
both platform acceptance and a user like can coexist with a scientifically
wrong result, and required separate expert assessment rather than treating
either signal as proof of correctness.
