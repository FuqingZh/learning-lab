# Exact evidence reuse is understood causally

The learner can now both classify cache-reuse cases and explain the causal
boundary: reuse depends on the complete scientific computation identity rather
than a tool version label alone, a successful no-hit is reusable scientific
evidence, and a timeout is an incomplete operational failure rather than
evidence. This closes the first lesson and unlocks annotation algorithms and
adapter boundaries.

## Evidence

The learner explained that changed runtime identity or result-affecting
parameters can change results for the same sequence, and distinguished a
completed no-hit from a timeout that interrupted computation.
