# Learning Lab

This is Fuqing Zhang's private, persistent learning workspace for building
transferable understanding across bioinformatics software and its computing
foundations.

The repository records a learning mission, trusted sources, demonstrated
knowledge, reusable lessons, and later review material. It is deliberately
separate from source repositories: its contents are personal learning state,
not authoritative product documentation and not implementation requirements.

## Structure

- `MISSION.md`: the concrete learning outcome and boundaries.
- `RESOURCES.md`: curated, version-aware sources used by lessons.
- `learning-records/`: knowledge the learner has actually demonstrated.
- `lessons/`: reusable lesson artifacts, created only when useful.
- `reference/` and `GLOSSARY.md`: compressed recall material, added after
  understanding is demonstrated.
- `NOTES.md`: teaching preferences and review cues.

The first track is SeqEvi, taught from protein-sequence identity through
annotation tools, evidence caching, storage, concurrency, operating-system
processes, and result consumption.
